# ÒsánVault Shared Packages

Reusable contracts and libraries live here after extraction and validation.

Planned package boundaries:

- `auth/`
- `database/`
- `ui/`
- `sdk/`
- `types/`
- `config/`
- `audit/`
- `notifications/`
- `events/`
- `logging/`
- `security/`

Do not copy legacy code into a package merely to relocate it. A package must have a defined ownership boundary, public interface, tests, and consumers before it is considered canonical.
